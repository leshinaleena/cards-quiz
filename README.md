# TOP RIDERS · квиз подбора карты для путешествий

Одностраничный сайт-квиз: 6 вопросов → подсчёт → 2–3 варианта в сравнении → переход к менеджеру в Telegram.
Чистый HTML/CSS/JS без сборки и зависимостей: вся графика в CSS/SVG, анимации на CSS и Web Animations API.

## Структура

```
index.html               разметка всех экранов
config.json              ВСЕ тексты, вопросы, правила подбора, карты, таблица сравнения, контакты, Метрика
config.demo.json         вымышленные карты для предпросмотра (?demo=1), на рабочем сайте не используются
assets/
  css/styles.css         стили, фирменные токены, 3D-карта, reduced-motion
  js/app.js              экраны, квиз, тасовка, результат, копирование в буфер
  js/card.js             3D-карта: наклон за курсором/гироскопом, блик, переворот, реакции на ответы
  js/scoring.js          логика подбора (читает правила из config.json)
  js/analytics.js        Яндекс Метрика и UTM-метки
  js/icons.js            собственные линейные SVG-иконки, чип, логотип
  favicon.svg
```

## Запуск и деплой

Конфиг загружается через `fetch`, поэтому сайт нужно открывать через веб-сервер, а не двойным кликом по файлу.

- Локально: `python3 -m http.server 8080` → http://localhost:8080 (с демо-картами: http://localhost:8080/?demo=1)
- Хостинг: загрузите папку целиком на любой статический хостинг (Netlify, Vercel, GitHub Pages, обычный сервер или S3). Сборка не нужна.

Полезные параметры ссылки:
- `?demo=1` — подставить вымышленные карты из `config.demo.json`, чтобы посмотреть результат;
- `?debug` — писать отправляемые цели Метрики в консоль браузера.

## Как редактировать config.json

### Карты (`cards`)

| Поле | Что это |
|---|---|
| `id` | внутренний код карты; менеджер видит его в скопированном тексте: «(код B)» |
| `label`, `tag` | название и фишка («Самый быстрый», «Оптимальный»…) |
| `active` | `false` — временно скрыть карту |
| `priority` | при равных баллах выше окажется карта с большим `priority` |
| `applePay`, `googlePay`, `booking`, `onlinePayments`, `remote` | `true` / `false` |
| `currencies` | `["USD","EUR"]` |
| `regions` | `["Европа","Азия","США и Канада"]`, причём написание должно совпадать с правилами вопроса о странах |
| `term`, `price` | текст для таблицы: «2–3 недели», «от 20 000 ₽» |
| `termDays`, `priceValue` | те же значения **числом** (дней / рублей), по ним идёт подбор по срочности и бюджету |
| `weights` | ручные баллы: `weights.<id вопроса>.<id ответа> = число` |

Незаполненное значение (`null`, `""`, `"___"`, `[]`) не даёт баллов и показывается в таблице как «уточняется».
Пока все карты не заполнены, квиз будет показывать экран «Ваша задача нестандартная», и это ожидаемо.

Карт может быть сколько угодно. При `scoring.relabelResults: true` (по умолчанию) показанные варианты
всегда называются «Вариант A/B/C» по порядку, а настоящий код карты уходит менеджеру в скопированном тексте.

### Как считаются баллы

Для каждого ответа клиента:
1. если у ответа есть `match` и карта ему соответствует → `+points` (по умолчанию 1);
2. если у карты есть `weights[вопрос][ответ]` → `+` это число;
3. если у ответа `"required": true`, а карта точно не подходит → карта исключается.

Правила `match`: `{ "field": "remote", "equals": true }`, `{ "field": "regions", "includes": "Азия" }`,
`{ "field": "currencies", "minLength": 2 }`, `{ "field": "priceValue", "lte": 20000 }`, `gte`, а также
`{ "any": [ … ] }` и `{ "all": [ … ] }`.

Итог: показываются карты с баллом ≥ `scoring.minScore`, максимум `scoring.maxResults`.
Если подошла одна, к ней добавляется ближайшая альтернатива. Если не подошла ни одна, показывается экран нестандартной задачи.

### Вопросы (`questions`)

`type`: `single` или `multi`. У варианта ответа можно задать реакцию карты в углу экрана:
`"card": { "edge": ["#цвет1", "#цвет2"], "label": "EUROPE", "icon": "pay" }`.
Доступные иконки: `pay`, `booking`, `apps`, `currency`, `remote`, `plane`, `fast`.
Диапазоны бюджета задаются в вопросе `budget` (подпись + `match` по `priceValue`).

### Таблица сравнения (`compare`)

Типы строк: `flags` (несколько булевых полей в одной строке), `bool` (с подписями `yes`/`no`), `list`, `text`.
Строки, где значения у вариантов различаются, подсвечиваются автоматически.

### Тексты, контакты, аналитика

- `texts`, `clipboard`: все надписи на сайте и шаблон текста, который копируется для менеджера;
- `brand`: ссылки на Telegram, телефон, канал и сайт;
- `analytics.metrikaId`: номер счётчика Яндекс Метрики (пусто — Метрика не подключается).

Цели Метрики (создайте их в интерфейсе как «JavaScript-событие»):

| Цель | Когда |
|---|---|
| `quiz_start` | нажали «Подобрать карту» |
| `quiz_step_1` … `quiz_step_6` | ответ на шаг (параметры: вопрос и ответ) |
| `quiz_result` | показан результат (параметр: коды карт) |
| `quiz_nonstandard` | показан экран нестандартной задачи |
| `contact_manager` | клик «Связаться с менеджером» |
| `contact_phone` | клик по телефону |

UTM-метки из ссылки (`utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`) запоминаются
на время сессии и добавляются в текст, который копируется в буфер.
