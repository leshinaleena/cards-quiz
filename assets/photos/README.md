# Фото для сайта

Пути к фото задаются в `config.json` (блок `photos`, у вопросов — поле `photo` у вариантов, галерея — блок `uses`).
Если файла нет, блок просто не показывается.

| Файл | Где на сайте |
|---|---|
| `hero.jpg`, `hero-2.jpg`, `hero-3.jpg` | слайдшоу на первом экране (вертикальные 4:5) |
| `band.jpg` | широкая полоса со слоганом (панорама, тёмный левый край) |
| `use-car.jpg`, `use-hotel.jpg`, `use-flight.jpg` | галерея «От аэропорта до отеля» (4:5) |
| `europe.jpg`, `asia.jpg`, `usa.jpg`, `world.jpg` | вопрос «В какие страны» (квадрат) |
| `loading.jpg` | фон экрана подбора (панорама) |
| `cta.jpg` | шапка блока «Обсудим детали?» (панорама) |
| `manager.jpg` | фото менеджера у кнопки Telegram (квадрат, только настоящее фото) |

Все фото обработаны по фотостилю брендбука (холодные тени, тёплые света) и сжаты: JPG качества 75–80 %.
