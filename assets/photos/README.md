# Фото для сайта

Положите сюда файлы с такими именами, и они сами появятся на сайте. Если файла нет, блок просто не показывается.

| Файл | Где на сайте | Размер |
|---|---|---|
| `hero.jpg` | первый экран, за 3D-картой | 1200×1500 (вертикальное), главное в центре кадра |
| `europe.jpg` | вопрос «В какие страны», вариант «Европа» | 300×300 |
| `asia.jpg` | вариант «Азия» | 300×300 |
| `usa.jpg` | вариант «США и Канада» | 300×300 |
| `world.jpg` | вариант «Разные страны» | 300×300 |
| `manager.jpg` | рядом с кнопкой «Связаться с менеджером» | 300×300, лицо по центру |

Чтобы сайт грузился быстро, сохраняйте JPG с качеством около 75–80 %. Тогда hero весит не больше 250 КБ, остальные не больше 40 КБ (например, через squoosh.app).

Фото менеджера должно быть настоящим, не сгенерированным. Имя менеджера впишите в `config.json` → `photos.managerName`.
